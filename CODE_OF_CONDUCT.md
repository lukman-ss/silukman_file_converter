# Code of Conduct

## Our Pledge

We want this project to be useful, respectful, and safe for contributors and users.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent while being precise about technical problems.
- Keep discussions focused on the project and its users.
- Avoid sharing private documents, credentials, or sensitive logs.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks.
- Publishing private information without permission.
- Posting exploit details or sensitive files in public issues.
- Deliberately misleading users about feature readiness or security.

## Enforcement

Project maintainers may edit, hide, or remove comments, issues, pull requests, or contributions that violate this code of conduct.
